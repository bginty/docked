Root cause and scope
The browser has a 15-second transaction deadline. Production pg_stat_statements
showed state UPDATE averaging 11,469 ms and reaching 16,562 ms, before the
remaining request work. The 3.7 MB expanded JSONB state was repeatedly detoasted
inside per-card validation loops. This is independent of the reveal animation.
The isolated restored database attributed 51.6 seconds of a 56.3-second update
to the lifetime guard. Materialising the same JSONB once per invocation in three
guards reduced the isolated update to 8.1 seconds. These are local measurements,
not a claim that Production has the same timing.
