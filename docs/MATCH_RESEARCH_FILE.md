# Match research file

Each prematch EPL file separates current canonical identity, source clocks, structured facts, conflicting/corroborating evidence, missing sections and model/market boundaries. Completeness uses an explicitly reviewed policy. Missing sections say `DATA_NOT_AVAILABLE`; no arbitrary completion percentage is manufactured.

An immutable snapshot stores the captured event identity and kickoff, policy hash, complete evidence identities, selected fact hashes, feature definitions and research hash. Staff can select the exact snapshot used by a content draft. Historical reconstruction uses its captured event/as-of/evidence set, including correction ancestry, so later rescheduling does not reinterpret what was known. Current rights and payload retention still apply. Metadata remains after licensed values expire; unavailable detailed values are not silently reconstructed.

Publication always checks today's canonical identity/status, full current event evidence, source permissions, expiry, correction history and conflicts. A previously approved assertion is suppressed if a later current correction or conflicting source changes its standing. Member content is a reviewed subset with only public attribution and reviewed identities. It is not the private complete research file.

`DOCKED_RESEARCH`, `MATCH_UPDATE` and `LINEUP_UPDATE` drafts require owner/admin/editor review. They never use the official Docked Edge ledger, badge, social tip projection, settlement or performance tables. A manual input cannot provide probability, fair odds, EV or a betting recommendation.

Features have descriptive states `DISPLAY_ONLY`, `MODEL_ELIGIBLE`, `MODEL_ACTIVE`. The full registry record is hashed and append-only. A separate computational definition hash avoids a circular dependency when a future model configuration freezes approved feature definitions. Current proposals have no fitted implementation, and research never changes their status or coefficients. Recalculation requests retain the prior prediction identity, keep the new prediction null and cannot replace a Phase5B calibration cohort.
