C. NBA SCORING SPECIFICATION — IMPLEMENTED TEMPLATE, NOT APPROVED RELEASE

Version docked-nba-events-v1. Provider field -> canonical -> base points:
Points              -> points         -> +1 each
Rebounds            -> rebounds       -> +1 each
Assists             -> assists        -> +2 each
Steals              -> steals         -> +3 each
BlockedShots        -> blocks         -> +3 each
Turnovers           -> turnovers      ->  0 (no proposed penalty)
ThreePointersMade   -> threePointers  ->  0 extra (already included in Points)

All seven mappings are implemented and synthetic-tested, not verified against a
licensed account. The raw contract additionally requires minutes/seconds, both
rebound splits, field-goal/three/free-throw makes and attempts, and fouls. A missing
raw field currently keeps the raw record incomplete; do not silently relax it.
The NBA template has no rarityVersion: no NFL rarity multiplier applies. Approving
new-sport rarity scoring would require a separate version/implementation and tests.
No new penalty, bonus, captain or best-game rule was introduced.

PG, SG, SF, PF, C and three FLEX = eight distinct players/cards. Multi-position
eligibility is explicitly reviewed, never inferred from stats. Open is uncapped;
Traditional needs an approved cap/salary distribution, not NFL's $4.4m by default.
Every eligible game in an explicitly frozen period contributes, including overtime.
Integer centipoints are authoritative; sum eligible event contributions once.
These weights produce exact whole base points; display two decimals. Existing
versioned scorer and snapshot policies remain authoritative for historical rounds.

Confirmed DNP follows the existing zero treatment. The current SportsDataIO adapter
marks played only when Games=1; Games=0, absence or zero minutes are NOT affirmative
DNP evidence. Obtain documented DNP status/appearance evidence and test it before
launch. This is a real provider-level completion blocker, not just wording.
Postponed/delayed/suspended/cancelled/abandoned states are explicit; unresolved
fixtures do not become final zero scores. Period membership and exceptional-game
resolution must follow the approved frozen-period/reviewer workflow.
Transfers retain stable identity and historical game/team mapping. Unknown contract
and jersey fields remain unknown. Two-way/development/reserve eligibility requires
an explicit policy; injured contracted players are not automatically excluded.

Correction pipeline: source revision -> immutable raw changes -> atomic delivery
receipt/checkpoint + recalculation request -> authorised existing scoring journal
-> authoritative team aggregation/ranks. Missing/stale fields remain pending.
The 72-hour template correction window and final-result review protect finalised
history; no mass backfill or prize recalculation was performed. Approve period
timezone/boundaries, round lock, roster, weights, salary and supply before release.
