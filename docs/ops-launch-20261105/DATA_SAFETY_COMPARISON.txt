Scope
Read-only comparison of the saved Console preview in
docs/qa/final-au-submission-20261105/data-safety-readback.txt against the

Material correction
The saved preview omits Diagnostics. The exact v30 bundle contains Google Play
Billing 9.1.0 and its Google Datatransport/CCT diagnostic path. This is distinct
from Docked's deliberately ephemeral, filtered product-query diagnostic display.
Google's official Billing release notes describe API-result and connection
logging for library reliability and error support. The current 9.1.0 implementation
was independently inspected rather than assuming every dependency is active.

Console handling recommendation
- Add Diagnostics collection: App functionality and Analytics (technical API/
  performance reliability); not ephemeral, because transport schedules/queues
  events; required because this build has no consent/opt-out for SDK diagnostics.
- Do not infer Crash logs from this finding.
- Existing Device or other IDs should cover the random billing session identifier,
  not only optional browser-push subscriptions. Its required/optional and purposes
  need to include the actual automatic SDK path (functionality/technical analytics).
- Diagnostics goes to Google for Google's library-performance/error-support use.
  An on-behalf-only service-provider exception must not be presumed merely because
  Google supplies billing. Without evidence establishing that exception, disclose
  the transfer as shared as well as collected. Apply the same analysis to the
  associated SDK session identifier. Do not invent a contract or consent exception.
- Google's payment-processor exception can cover payment credentials which Docked
  never accesses; it is not a blanket exemption for app-bundled SDK diagnostics.

Deletion / telemetry checks
The source requires a recorded deletion request and disabled account, erases Auth
credentials/identifying metadata, removes the active profile, and keeps necessary
opaque ledger/competition/audit references. Retries lock the queue row and do not
duplicate completion audits. Shared beta identity erasure remains operator-reviewed;
public mode has its tested worker. Do not promise immediate erasure of every record
or call still-linkable retained evidence anonymous. Prior isolated hosted deletion
acceptance remains valid; no deletion mutation was repeated for this comparison.
The anonymous analytics endpoint returns consent disabled and private/no-store;
synthetic identity and account-deletion endpoint readbacks are recorded separately.

Privacy wording follow-up
The approved v2 phrase about Android/Google diagnostics under their own settings
does not clearly distinguish OS opt-in Vitals from app-bundled automatic Billing
diagnostics. A narrow additional clarification is recommended for owner review:
"The Android app includes Google Play Billing Library. When it is initialised or
used, it sends billing-operation results, technical app/device information and a
per-session identifier to Google for reliability, performance and error support.
These SDK diagnostics are separate from Docked's optional usage analytics and are
not disabled by that analytics preference. Google handles them under its privacy
terms." This correction has not been published or represented as already approved.
