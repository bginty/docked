Implemented in this checkpoint
- Existing card-economy allocator accepts explicit isolated NBA products using
  the existing Standard/Premium nine-card prices (700/5,000) and approved weights.
- Preparation is additive, idempotent and disabled. It does not add players,
  grant credits, allocate cards, activate products or modify NFL records.
- NBA allocation only accepts marked synthetic fixture identities. Real NBA
  issuance has no enabled path in this change. Premium excludes Core/Rare/Elite.
- NBA receipts and cards retain sport, rarity, serial and immutable purchase
  terms. Competition multiplier presentation is 1.0 for NBA.
- Shared PackShop can filter products/history by sport and uses the existing
  purchase confirmation, idempotency, reveal, replay and wallet components.
- NBA collection adds player/city search and verified-position filtering.
- A roster-only review command uses the existing ingestion bridge and reviewed
  identities, requires 30 distinct teams, reports eligibility/position coverage,
  and grants neither issuance nor activation.
- Statistics service now rejects duplicate identities, incomplete team coverage,
  unknown teams/positions and malformed roster batches before scheduler import.
  Membership does not automatically become verified contractual eligibility.

   players. Do not rename them to real players without identity/source evidence.

   existing /BoxScoreFinal/{game} for postgame statistics. Configure the existing
   SPORTSDATAIO_NBA_KEY server secret and reviewed permit only after approval.

   requires ALL-STAR ($9.99 USD/month as checked 22 October 2026). G/F taxonomies
   still need specific approved PG/SG/SF/PF eligibility evidence. Its terms permit
   commercial use but explicitly do not clear third-party rights. No subscription
   was purchased or terms accepted on the owner's behalf.
4. NBA.com restricts fantasy-product reuse. It is not an authorised ingestion
   source for this release. No restricted endpoints were scraped.

   accepts NFL/AFL only. No widening migration or permanent NBA inventory was
   applied. A reviewed isolated-fixture persistence boundary, admission checks,
   marketplace visibility and bridge into the existing NBA lineup inventory must
   be completed and database-tested before enabling hosted NBA pack/trade actions.
   This is remaining ENGINEERING, not a claim that licensing blocks all testing.
6. Current hosted NFL only permits fixed-price credit sales. Private offers/swaps
   are intentionally disabled in member-test-wallet. Their core test success is
   not permission or evidence of hosted availability.
7. Owner decision received 22 October 2026: use the current 5% seller commission,
   rounded half up to whole credits and capped at 2,000 credits, for NBA as well
   as NFL. This supersedes the request's 7.5% wording. No current fee code or
   historical settlement values need to change.
8. No authenticated Production browser session was available in the inspected
   browser inventory. Do not count local identity fixtures as hosted acceptance.
