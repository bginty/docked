- [ ] Reproducible historical validation with untouched/contamination disclosure.

- [ ] Effective-dated country/state approval, legal ages, eligible operators, notices and communications rules.
- [ ] Verified operating entity, support contact, final Terms/Privacy, complaint/correction process.
- [ ] Separate preview/production Supabase and email credentials; email/domain authentication; allowlisted Auth redirects; confirmation enabled; anonymous signup disabled; admin MFA.
- [ ] Hosted RLS/advisor checks, complete authenticated end-to-end journey and external security review.
- [ ] Measured queue throughput, latency, quote decay, crash recovery and cap behaviour under concurrency.
- [ ] Production monitoring and on-call ownership; encrypted backup and restoration drill.
- [ ] Record one immutable public launch timestamp and release authority; never regenerate on deployment.
- [ ] Explicit approval for precise preview commit, target hosting project, domain cutover and rollback.

## Education-only release — separate decision

May keep tips, registration and outbound communications disabled. Still requires verified entity/contact/policies, hosting/privacy review, preview approval and production authority. Do not enable tip features merely because educational content is available.
