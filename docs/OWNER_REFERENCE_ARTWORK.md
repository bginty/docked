# Owner dashboard original artwork

Two original raster assets were generated with the built-in image-generation tool for this task. Both depict fictional adult athletes, not identified professional players. The request excluded team/league logos, manufacturer marks, sponsor marks, names, numbers and text. Existing Docked logo assets were reused separately, unchanged.

The wide asset uses a dark-red helmeted American-football quarterback, pale-blue soccer player and black/red sleeveless Australian-football player, grouped centre-right with dark negative space, cinematic navy smoke and blue edge lighting. The sidebar asset is a dramatic helmeted navy football upper-body portrait with a shadowed face, smoke and blue rim lighting. These preserve the supplied reference's three-sport composition and lower-sidebar silhouette while replacing its marked professional photographs.

Original generation outputs remain in local `source-assets/owner-reference-v1/three-sport-banner.png` and `sidebar-football.png`. This directory is already excluded from Git. The application uses resized/compressed WebP derivatives only:

- `public/brand/docked/admin/three-sport-banner.webp`: 1600 px wide, approximately 70 KB.
- `public/brand/docked/admin/sidebar-football.webp`: 480 px wide, approximately 24 KB.

The complete generation prompts and original outputs are retained in the task history. No original Docked brand file was overwritten. Decorative use has empty alternative text; functional branding and controls retain accessible names. No licensing permission for the supplied professional imagery is asserted.
