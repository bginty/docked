# Manual Preview trial controls

The trial endpoint is `POST /api/internal/provider-trial`. It accepts only a JSON `permitId`, a maximum 256-byte body, no query parameters and an authenticated operator bearer. The API key stays inside the Sensitive hosted environment. The stored permit contains only the operator token's SHA-256 hash, one fixed operation, optional exact reviewed competition/configuration, issuer and expiry.

Only the exact Docked Preview project, database and Vercel project/origin are accepted. General market polling, legacy odds polling, scanner scheduling, automatic publication, forward paper, public delivery and commercial features remain explicitly off. The normal importer without a trial permit cannot use this manual exception.

Migration `20261003225203_phase5a_manual_provider_trial.sql` creates four private RLS tables with no browser or production runtime grants. An existing administrator with a genuine current AAL2 session must create the reviewed rights record and each permit. The rights record and its cumulative ceiling are immutable; revocation is recorded. The single trial row cannot be replaced to reset its budget. Review validity is at most 32 days; permits expire within 30 minutes and cannot outlive the review.

Each request atomically locks the trial and shared provider health row, validates its exact cost and scope, and commits its reservation before network access. The total allowance is at most 250 credits and 25 attempts across all dates and months. A free `/sports` probe is the only request allowed while provider quota is unknown. Current odds reserve one credit per configured region; fixed recent scores inspection reserves two. NFL remains free fixture catalogue only. Historical requests are not permitted without a separate reviewed implementation and documented plan entitlement.

Only one request can be in flight. An unfinished request after a crash blocks another request for operator review; replay never generates a second provider call. Reservations are not refunded after failures or lower reported charges. Response quota headers are recorded before parsing or another request. A charge above the reviewed estimate or a failed request withdraws trial source authority and blocks continuation. This deliberately requires reviewed repair rather than automatic retries. Unexpected provider billing cannot be undone; the system records any discrepancy and stops.

Expired or revoked rights withdraw current data and reference eligibility. Source health must separately contain the reviewed rights reference and display/retention capability before a non-bootstrap request. Raw scores evidence is private and retention bounded; it never settles a ledger. Existing licensed canonical evidence and immutable ledgers are preserved. Unknown ownership remains a shared unreviewed group, and unknown standard-price classification cannot produce a MarketReference.

The data-only diagnostic invokes the existing MarketReference engine against retained observations. It never invokes the probability model or creates scanner candidates. Missing configuration or source authority remains unavailable. Regional permissions remain unchanged: staff evidence inspection does not grant member or public display rights.

Local validation: eight PostgreSQL/PGlite invariants and five platform tests pass. They exercise browser and production-role denial, genuine staff MFA, exact scope/token/cost, replay, unknown quota, cumulative budgets, bounded free attempts, expiry/revocation, immutable observed costs, interrupted/failed request withdrawal and invocation-bound completion. Canonical mapping rejection closes the trial while keeping its evidence. Known account or total-budget exhaustion blocks another request, including free metadata. A successful free quota probe that reveals zero remains a successful account observation and withdraws source health. Tests use only fictional isolated data and make no provider requests.
