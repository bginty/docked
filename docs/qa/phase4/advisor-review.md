# Hosted advisor review

Only Docked Preview `bckkllmndoxzpzdqrevb` was inspected. Initial Phase 4 receipts were taken after migration 7; final receipts were taken after acceptance and teardown. The final security response contains 79 private-RLS informational findings and no SQL warning/error. Final performance counts are 53 unindexed foreign keys and 12 unused indexes (initially 18 unused).

- **No SQL security ERROR.** Private application tables deliberately have RLS with no browser policies and revoked browser grants; default denial is the intended boundary. Do not add permissive policies merely to clear the informational notice. Four member tables retain reviewed own-row SELECT policies. [RLS advisor explanation](https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy).
- **Initial Auth WARN: leaked-password protection disabled.** Supabase documents this feature as Pro and above. The owner approved Free only; no upgrade was made. The final advisor did not return this Auth notice after teardown; no password-protection change was made, so its absence is not treated as remediation. Strong reserved test passwords, confirmation and real staff MFA were exercised, but these do not replace leaked-password protection for a future public launch. [Provider requirement/remediation](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection), checked 3 October 2026.
- **Performance INFO: unindexed foreign keys.** Review them against real query plans and load before launch; the preview contains no sporting workload and cannot establish a measured performance defect. Benchmark the source-cohort/market-reference lookups, account-erasure joins and leaderboard/notification paths when authorised data is supplied. [Foreign-key index guidance](https://supabase.com/docs/guides/database/database-linter?lint=0001_unindexed_foreign_keys).
- **Performance INFO: unused indexes.** Empty or tiny preview tables and recently created indexes explain this signal; no index was dropped based on the test workload. [Unused-index guidance](https://supabase.com/docs/guides/database/database-linter?lint=0005_unused_index).

Free-plan backup/PITR and a production service-level guarantee are not claimed. A dedicated least-privilege server database role, tested full recovery, load testing and the documented launch/legal controls remain release prerequisites. Service/secret credentials stay server-only.
