# Official forward record presentation

This is isolated presentation and arithmetic evidence. Every populated record in these fixtures is explicitly fictional and exists only under tests; no user, model prediction, sporting result, publication or engagement was inserted into an application database.

The final focused browser run passed **2/2** cases at 360 and 1366 pixels (18.2 seconds). Each case rendered empty, restricted and populated states, retained every win/loss/void/pending/disputed row, checked date absence before the first publication, contained horizontal table scrolling, and ran axe. There were no console errors, page overflow or axe violations. Six screenshots are stored beside [the browser receipt](browser-final.json). Mobile empty and desktop populated/empty screenshots were visually reviewed; the final captures include the preserved date/model filters. The unavailable state displays unknown metrics rather than false zero returns.

An independent visual review caught desktop “Unavailable” wrapping in the first auto-fit metric grid despite passing axe. The grid now uses four columns on desktop, three at medium widths and two on mobile. The final test explicitly requires each metric value to occupy one line. The [earlier receipt](browser-before-metric-width.json) and [desktop image](initial-harness-failure/before-metric-width-1366.png) are preserved.

The first run passed desktop but failed one mobile harness assertion: `End` was incorrectly expected to horizontally scroll the table. Its [failure context](initial-harness-failure/error-context.md) and screenshot are preserved. The test now uses the actual horizontal navigation key, `ArrowRight`, while retaining focus, overflow, complete-row and accessibility assertions. No production workaround was introduced for this harness mistake.

Focused platform checks passed **27/27**: official metric boundaries, exclusion of other evidence categories, complete-population averages, unknown settlement/chronology handling, filters preserving the global start, corrected losses/provenance links, independent-model card failure states, community recognition anti-gaming, existing educational/CMS presentation, and artifact preservation. Type checking and scoped ESLint passed. The later complete isolated browser run and corrected presentation-contract reruns are documented in [Phase 5B experience acceptance](../EXPERIENCE.md): all 84 distinct cases have passing evidence, with initial/intermediate failures preserved. Actual hosted model/publication paths remain separate acceptance evidence.

The official model evidence card shows retained version, input cutoff, calculation/as-of times and hashes. Missing independent model evidence suspends the presentation and withholds TAKE, fair price and estimated edge. Legacy market-derived comparisons are labelled research fair odds. Optional historical research tools remain available, but no reconstructed tips or historical betting ROI are required to populate the official record.
