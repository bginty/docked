DOCKED PACK REVEAL NAVIGATION — REVIEW CANDIDATE
2026-11-07 — Not deployed. Owner approval required before Production.

ROOT CAUSE
PackOpening passed card inspection to its parent. Several callers closed the
pack before opening player details, unmounting the active reveal session.
The old local progress value stored an index but not whether that card had
already been revealed. Ordinary browser Back also needed separate pack and
player-detail history entries.

IMPLEMENTATION
NFL/AFL/NRL player inspection is now owned by the mounted pack component.
The existing collectible artwork, statistics and detail controls are reused
inside a child sheet. Back to Pack, Close, browser Back and the native cancel
contract dismiss only that sheet. The pack's current card and reveal phase
remain intact.

Under the revealed card: secondary View Player and primary blue Next Card →.
The last card uses View Pack Summary. Share My Pull, Reveal All and Exit Pack
remain available as smaller controls. Progress remains Card N of M.

Device-local v2 progress stores only index, revealed and updatedAt, keyed by
member and server receipt. Resume Pack uses the existing authenticated pack
reader; the local record is never a source of cards, rarity or ownership.
Legacy progress is readable. Explicit replay does not overwrite an incomplete
normal session. Disabled storage still allows in-memory navigation.

SERVER / DATA BOUNDARY
No migration, API, purchase, price, odds, supply, wallet, issuance, ownership,
refund, authentication or sport-visibility code changed. NBA stays on its
existing reveal path. All testing used synthetic receipts and isolated fixtures.
No live purchases, balance adjustments or inventory changes were made.
