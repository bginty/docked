2. Customer-facing changes
- Compact native round picker replaces the oversized modal. Visible labels wrap,
  keyboard focus remains visible, and device-native selection is available.
- NFL/AFL/NRL use Round; NBA's existing Week terminology is preserved without
  changing its hidden status. Seasons and internal identifiers remain stored.
- Open, upcoming, unavailable, closed and final labels use actual saved fields.
  Paused rounds cannot claim entry is open. Unknown opening times use planning
  language. Practice/Test context remains visible where relevant.
- Play secondary links are compact. Fixed a legacy sport-navigation CSS rule
  that stacked the Australian selectors, narrow prize-label wrapping and additive
  NFL spacing. Unsaved-draft guards, explicit historical links and rules remain.
- Social has a compact expandable composer, fitting feed tabs and a 24-card
  attachment page. Drafts and selection survive minimising, errors and paging;
  first selection and last deselection retain keyboard focus across sport filters.
  Physical Samsung testing additionally found cramped dirty-form buttons. They
  now form two readable mobile rows, with Post prominent; clean forms retain
  their original action layout. Text-fit checks cover 320/360px and 125% text.
- Wallet resume signals are coalesced without value caching. An invalidation
  during a read requires a fresh authoritative read; obsolete responses cannot
  update the balance. No mutation is automatically retried by this mechanism.
- Marketplace polls join an existing read rather than making every slow response
  obsolete. Mutation signals still invalidate prior reads, and a confirmed command
  triggers fresh state. Account changes remount private view state immediately.
- Notifications now exposes the existing Retry action on load failure. Unavailable
  data cannot present default notification preferences for accidental saving.
- Supported player game-log labels use the same Round terminology. Unsupported
  detailed statistics views remain unavailable rather than inventing data.
