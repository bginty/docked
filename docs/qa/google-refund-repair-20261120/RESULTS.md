# Google refund release decision

The closed-gate repair routes the existing Google push endpoint and the five-minute Vercel scheduler to the commercial reconciliation worker. The public launch decision is pending hosted acceptance and a separate founder authorisation.

## Source and environment

The 20 November launch stopped on application source `6e96e61192b82ee576aa0a8365808081a98b30fa`. Vercel and the public website were checked again. The source, deployment, cron path, deployment protection and closed registration readback are recorded in [live-baseline.json](./live-baseline.json).

The inherited scheduler flag selected the retired beta worker even when both beta modes were false. A synchronous exception interrupted the construction of the promise array before the commercial worker could start. The repair shares the eligibility rule with the legacy worker constructor and schedules each eligible worker through an independent promise. Disabled or failed dispatch returns HTTP 503. A deferred commercial refund now also returns 503 with the health counters and logs attention. Durable jobs retain the existing lease, retry and escalation thresholds.

The authorised Cloud Console subscription Details read verified the topic, canonical callback, audience and signer. The callback previously constructed the beta worker while the separate commercial receiver lacked its three required bindings. With both beta modes explicitly disabled and commercial service enabled, the canonical callback invokes the commercial receiver. It uses the Google key set and the exact configured issuer, audience, email identity, subscription and Android package. The prior protected beta/isolated relay flow retains its original authentication. The existing Google Cloud configuration needs zero writes.
