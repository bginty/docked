SCORING HISTORY
The general rules page incorrectly used published fantasy competitions as its
history source. That yielded Round 6, Round 7 and a practice round even though the
independent NFL historical publication already contained real rounds 1–9.
Production was inspected read-only: Round 8 contains 980 player-game records
across 14 games, with 272 reviewed offensive-player mappings; Round 9 has 71
records across one game, 21 mapped. These are not claims of round finality.

The general screen now uses sport navigation, sport rules and a restricted,
authenticated, no-store history API with pagination/search. NFL history uses
reviewed identities and latest corrected revisions, excludes synthetic/tombstoned
records and distinguishes missing scores from zero. Base points apply the shown
Full-PPR reference version; rarity multipliers are explained separately. Saved
competition rules/results and explicit competition/version routes are preserved.
AFL/NRL archives currently contain match results, not player-game statistics;
their screens disclose this instead of inventing scores. No round was opened.
Evidence: scoring/README.txt, scoring/production-readonly.json,
scoring/before-320.png, scoring/nfl-after-320.png, scoring/afl-after-320.png,
scoring/nrl-after-320.png (also 412px and desktop variants).

PACK REVIEW AND SHARING
All pulls use one aligned review-row component, including the gold Best Pull
variant. Names, positions, teams, rarity, serials and equal Share/View buttons
have stable placement. All nine cards remain accessible; 200% text gets a wider
action row. The duplicate sharing dropdown/prompt is removed from pack summaries.
Replay still says original result and never claims a new award.

Share freezes the exact selected card, lazily prepares its existing artwork and
opens supported native/file sharing without another card-selection step. Downloads
are 1080 x 1920 PNGs; no account, wallet, transaction or private card IDs are
exported. Cancelling preserves the pack. Slow browsers whose activation expires
offer Share Image for a fresh gesture; unsupported browsers offer Save Image.
Optional code preloading does not rasterise nine images. Loading keeps button
dimensions stable; module-load errors are recoverable without exiting the pack.
Evidence: pack-review-sharing/before-390.png, after-390.png, after-bottom-390.png,
after-320-text-200.png, share-legendary.png, share-ultra_rare.png and the two
docked-afl-*-pull.png downloads in that directory.

PURCHASE PERFORMANCE AND RECOVERY
The recorded hosted baseline has one buy/open pair: 8,406 ms + 9,481 ms network,
17,887 ms total. It is one observation, not p50/p95. Read-only database counters
identify the guarded beta aggregate UPDATE as the largest observed cost (83
calls, mean 8,400.4 ms). No financial guard, lock or verification was bypassed.

This release attributes authentication, provider verification, transaction/lock,
issuance, persistence, view and acknowledgement through private Server-Timing
headers and client journey timings. Nested spans must not be added together.
Reveal modules/assets preload while existing operations run. Non-essential
history refresh no longer delays or invalidates an already committed purchase;
confirmed receipts and pending request identities support safe recovery/reload.
The animated transition starts immediately, uses real processing/securing/ready
states, adds no artificial delay and respects reduced motion. Ready requires the
authoritative committed receipt. No card is presented as owned before commit.

Native PostgreSQL 17.10 isolated benchmarks ran 20 samples per operation, including
actual ledger/issuance/replay constraints. Google provider HTTP was mocked. They
do not include hosted Auth, provider latency, production guard volume or native
checkout. Candidate tails/open median were sometimes higher: NO BACKEND SPEEDUP
HAS BEEN ESTABLISHED. Further hosted percentiles require enough authorised samples.
See PURCHASE_PERFORMANCE.txt and purchase-timing-postgres.json for stage p50/p95/
maximum, fixture limitations and exact accounting assertions.
