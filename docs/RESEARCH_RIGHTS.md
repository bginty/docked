# Research rights and retention

Manual entry requires approved manual or automated retention rights, an active source review, an exact event mapping and analyst/admin/owner MFA. Retention alone does not allow public display. Public content independently requires `publicDisplay=ALLOWED`, commercial and storage permission, the configured jurisdiction, current review/effective dates and unexpired payload retention.

Facts store nullable upstream publication time separately from observed and ingested time. An unknown publication timestamp stays null. New target-match results cannot precede that canonical match's kickoff. Source-reported dataset scores without authoritative regulation finality cannot enter the structured result ledger automatically.

Payload retention is bounded by the source's explicit maximum days and effective expiry. The worker purges expired fact/dataset payloads in bounded batches even when automation is disabled. Immutable metadata, evidence hashes, source references and correction links remain. Historical snapshots therefore never imply that licensed values are retained forever. If payload evidence or current authorization is unavailable, the detailed value view fails closed while immutable metadata remains auditable.

Supersession and withdrawal append rows. Source rights changes never rewrite published betting or model histories. Research evidence cannot directly mutate Phase5B predictions, outcomes, official start boundaries or canonical settlement ledgers.

The adapter registry rejects all arbitrary URLs, redirects and unreviewed endpoints. Public evidence URLs cannot contain credentials or query strings. Fetch bodies are bounded; unsupported shapes and adverse quality findings stop ingestion rather than becoming factual records.
