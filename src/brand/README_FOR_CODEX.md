## Important implementation rule for Codex
Use these supplied assets directly. Do not redraw the Docked mark with CSS, text, emoji, icon libraries, or approximate geometry. Keep aspect ratio locked and do not stretch, rotate, recolour, add shadows, or alter the mark.

## SVG note
The SVG files in this pack are SVG containers that embed the approved high-resolution raster artwork. This preserves the approved appearance and is immediately usable in web/app builds, but they are not hand-built vector paths. If a graphic designer later supplies true vector master artwork, replace these SVG files while retaining the same filenames and usage.
